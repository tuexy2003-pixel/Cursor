# PRINCIPLES vs HEURISTICS (2026-10-05)
## A. HARD INVARIANTS (almost never violate)
1. The latest human-approved STORY_LOCK wins for story-specific values. Superseded assets are marked STALE; files are not deleted or rewritten.
2. An explicit human correction beats any skill default, until the skill is updated.
3. Proof boundary: a proof surface proves only what it literally shows. It cannot invent the actor's intent, location, payment causality or a retailer promotion.
4. Research mode never invents evidence. Staged/creative economics are labeled FICTIONAL/STAGED and never presented as a real retailer promo.
5. Reference-first production: when a suitable real base exists, edit it (smallest localized edit) and do not freehand-reconstruct retailer UI.
6. Never silently compress or squeeze native UI rows to fit content. If it doesn't fit, choose another real base or a natural scroll state.
7. Story-specific visible dates, times and weekdays come from the continuity ledger, not from the reference image.
8. Cross-slide congruency: no impossible state or time transitions (for example "tomorrow" followed by the party already happening with no time change).
9. Discount-headroom firewall: never add an expensive item only to enlarge the subtotal or discount. Items must be story-motivated.
10. Re-edits start from the original base, never from a drifted or degraded output.
11. Any real object added to an image is edited in using a real photo of that exact object as a reference.
12. Real products use the current generation and live price, verified before lock.
13. Rights: personal or unknown-rights images (Pinterest pins) are REFERENCE ONLY and their pixels are never shipped. Only CLEARED images may be a BASE.
14. Never send messages, place orders or post without explicit human approval. DoorDash carts are referenced, never checked out.
15. The money path appears only as the native "mydashperks.com Discount" line on the order surface. It never appears in chat bubbles, never on S1, and never as a savings slide.
16. Frozen architecture (V1.2, CAS, Gates 1/2A/2B, campaign salience, Desire/Utility gate, scouts, Live Heat, firewall) is not modified without explicit authorization.
17. No burned real names or handles of private people. Amounts and clocks are internally consistent.
