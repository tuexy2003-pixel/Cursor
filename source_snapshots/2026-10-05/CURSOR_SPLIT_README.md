# Cursor handoff split

The original handoff exceeded Cursor Agent's 10 MB attachment limit.

Upload `handoff_cursor_core.zip` first. It contains all text, JSON, skills, contracts, source/config, story locks, reference documentation, regression tests, and manifests required for architecture and initial implementation.

The example image assets are split into `handoff_cursor_examples_a.zip` and `handoff_cursor_examples_b.zip`. They preserve their original relative paths under `examples/` and can be added after the core handoff when Cursor needs actual visual examples.

The three archives together reproduce the original handoff content, except for this split README.
