## 1. Creative order (locked after “prior mixes trash”)
1. **Beat** — what someone notices / feels in the next ~10 seconds.
2. **Story clock** — when is this happening? Wrong clock = trash.
3. Each beat/slide must make the **next inevitable**.
4. **Assets last.** Never start from “we have a porch photo” or fill bubbles to match files on disk.

Modes (ENGINE): Remake / Director / Hybrid — mine proven **hook → proof** shells; don’t collage.

---

## 2. Story clock (carousel)
| Situation in story | Order / proof UI must feel like |
|---|---|
| Just ordered / mid-fight / “tell me not to” | **Heading your way / preparing / in progress** — house not delivered |
| Already ate / hours later / “worth it” after delivery | Order Complete OK |
| Broke leftover penny | Cash App / balance matches math |

Also:
- Phone status time, chat `Today at …`, and payment stamp must be **already past** vs real post time.
- Never ship a future evening time when it’s afternoon.

Shared carousel vibe: **hook** (notifications + top text, text convo, or photo) → **proof** (order, dasher convo, or money).

---

## 3. Chat-slide QA (flagged repeatedly — fail any = rebuild)
- **11–13 bubbles** at full conversational size. Short 5-bubble threads are not enough.
- **Fill the screen** like the Dre gold post — **no big empty black gap** under the chat header.
- Builder: real iOS Messages (`build_imessage_ios26.py` + image bubbles). Scale ~**0.732**, `top_space` ~**40–80**. Prefer this over third-party fake-iMessage sites (layouts look wrong).
- Same calendar day → timestamp **`Today at [time]`**, not “Fri Sep 26” style.
- **Fresh contact name every variant** — never reuse Dre, Kai, Malik, Terrence, Jalen, etc. across posts.
- Curly apostrophe in you’re / don’t when natural.
- Status battery / unread / service can sell “real phone”; keep coherent with time.
- Image bubble of order: sized so thread still fills (width_frac often ~0.32 when packing 11+).

### What chat text must NEVER say
- mydashperks.com, “discount,” “promo,” “free DoorDash,” “student perk,” hard CTA.
- Soft gossip only. Site may appear as a **native green line on the order UI**, not in bubbles.

### Math (assert exact before render)
- Start balance − order total = leftover (Cent: **$8.09 − $8.08 = $0.01**).
- Line items must sum: subtotal ± fees ± perk ± tax = **Total**.
- Perk line amount ↔ spoken/overlay story if any.
- Payment row amount = Total; date/time match clock rules.

## 5. Landing / conversion congruence
- Soft hero (“see what’s available / amounts vary”) under creatives that imply a concrete credit → **500 clicks / 6–8 sales** class failure.
- Hard shell that worked (Rewardly / old v0): **UP TO $X DOORDASH**, short steps, big **CLAIM YOUR REWARD**, survey/offers after.
- Chat/Cent = **reach / entertainment** → colder clicks. Don’t expect tut-pin conversion rates from fight stories.
- Don’t giant-URL the hook on entertainment posts (undisclosed-ad callouts). URL/proof native in UI when needed.
