# Cursor ideation — new carousel ideas (not just Cent clones)

Use with CURSOR_TASTE_AND_TRASH.md + CURSOR_GOLD_CENT.md. Cent = **bar**, not the only story.

## Before you pitch (every idea)
1. Name the **10s beat** in one line (feeling, not format).
2. Name the **clock** (just ordered / mid-fight / morning after / payday / leftover cash).
3. Name **hook type** + **proof type** (chat | notifs | photo → order | money | dasher).
4. Lane: Scale / Scout / Sequel.
5. YES-without-brand: still slap with perk line removed?
6. Exact math sketch ($ start → $ order → $ left). If math is cute-but-fake, kill it.

Max **3** candidates. Refuse trash clocks before assets.

## Idea engines (rotate)
- **Permission fight:** “tell me not to” → does it anyway (Cent family). Fresh name + new food/clock.
- **Leftover flex:** absurd small balance after a real-looking order.
- **Wrong friend advice:** “get a salad” / “save it” → proof they didn’t.
- **Couple / roommate split:** who paid, who owes, screenshot proof.
- **Notification stack:** 3 notifs that imply chaos → money or order proof.
- **Sequel:** same account, same cast energy, new beat — not copy-paste part 1.

## Don’t start from
- A plate photo you already have.
- “Put mydash in the chat.”
- Model C fill-bubbles-to-match-files.
- Retail plush/$2 tut energy on a DoorDash credit story.

## Pitch format (send Tyrel this, not a collage)
```
BEAT: …
```

Wait for lock before production specs/slides.
