**What differs psychologically:**

**Lesson:** the object is not the engine. Swapping the object while copying the plot fails.

## C5. McChicken "I'm so pissed" (P03, MID): why it sits in the middle
- **What carried it (217K):** the absurd proof detail (straw in, 859) and the injustice.
- **What capped it:**
  - Receipt-first with the deal visible on the hook slide.
  - A $0.00 tip, which made the dominant cluster (tipping 866 / 661 replies) *against* the narrator.
  - The owner says it read as an ad and didn't convert.
- **Contrast with P01:** both show the order first. P01's overlay stated a *self-blame* mistake, so viewers mocked the narrator affectionately. P03 blamed the brand/dasher, so viewers audited the narrator (the tip).
- **Lesson:** when the order is the first slide, the narrator must own the mistake. The tip line must not hand viewers a villain-narrator.
