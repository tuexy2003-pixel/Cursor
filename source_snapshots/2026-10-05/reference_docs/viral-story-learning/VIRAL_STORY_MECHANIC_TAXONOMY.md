# VIRAL STORY MECHANIC TAXONOMY

Abstract mechanics that survive swapping the object, setting, character and amounts. Built Mon 2026-10-05 ET from the cards in `VIRAL_CREATIVE_EXAMPLE_CARDS.md`.

**What a mechanic is here:** a *structural relation* between who knows what, who did what wrong, and what the viewer is left to do. A mechanic is never a plot, object, line or amount.

**Swap test protocol, applied to each mechanic:**
1. Swap the OBJECT to a different category of similar or lower desire.
2. Swap the SETTING/RELATIONSHIP (couple → roommate/parent/coworker/stranger).
3. Swap the SURFACE (iMessage → lock screen / Notes / Snapchat / receipt / camera roll).
4. Remove the discount entirely.

A mechanic **SURVIVES** if the viewer's job (judge / wonder / audit / replicate) is still intact after each swap. "Survives without discount" = YES is required for STORY-family mechanics. Where real data contradicts or confirms a swap, the example is cited.
