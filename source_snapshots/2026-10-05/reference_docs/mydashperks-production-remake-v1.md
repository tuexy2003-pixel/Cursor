## Evidence layers (never confuse them)

1. **Story layer** — human mechanic (care announce, attitude hook, gift chat). Entertainment first.  
2. **UI reality layer** — real app screenshots / real item thumbs / real fee structures from a cart we built or a reference SS.  
3. **Plate layer** — phone bezel, hand, desk, selfie crop (Google / Pinterest / owned library). Framing only.  
4. **Offer layer** — MyDashPerks as secondary inspectable math (named `mydashperks.com −$XX`) or survey CTA — never unsupported cashback chat claims.  
5. **Account layer** — what this account can own (faces, rooms, reactions). Prefer face-barely-showing / edges / POV hands when identity isn’t locked.

Glitchy control-room on the PC already has phone templates, avatar reference packs, and GPT-as-prototype doctrine — reuse patterns, don’t reinvent.

## Standard remake pipelines

### A) Receipt / order UI (GE-001–003, GE-005, Cand1 slide 2)

1. Build the real cart in DoorDash (or target app) on browser — exact items we want visible.  
2. Screenshot checkout / order-complete on desktop if needed.  
3. Pull a **mobile plate** (Google image search / owned `*mobile*.png` / blank-phone composition from Glitchy library).  
4. GPT (or Higgsfield later): **keep plate composition; replace only the phone display / center UI with our cart SS**; preserve bezel, hands, desk.  
5. Surgical edit: insert named MyDashPerks discount line; recompute totals so math congruence holds.  
6. Congruence QA checklist (fail = regen):
   - item names match thumbs  
   - subtotal + fees + tip − perk = total  
   - timestamps align with chat slides  
   - restaurant name consistent across slides  
   - no leftover reference restaurant/account chrome  
   - perk is secondary (not slide-1 hero unless utility-alert format)

### B) Fake text / chat (GE-006 mid, Cand1 slides 1/3/4)

Prefer **owned chat renderer** (Pillow / HTML we control) over random text-generator sites — same bubbles every time, editable copy, no watermark surprises.  
If using an external fake-iMessage tool: strip watermarks, match font/size to platform, lock bubble order to spec.

### C) Attitude / soft-face S1 (GE-008 forehead/edges, GE-006 eyes-only)

1. Pinterest / Google: “forehead edges selfie sky”, “eyes only selfie night”, hands-only POV — face barely showing.  
2. Do **not** clone golden-example faces or watermarks.  
3. Overlay original hook text (new wording).  
4. Optional: green-screen meme character (GE-004) instead of real face when account identity isn’t ready.

### D) Voiceover / Suno text-stories

Separate lane. Still frames + carousel ship first. Sound–text lock (GE-008) needs Remotion/editor pass — don’t block receipt pipeline on it.
