- Any research/generation run scope (Tyrel authorizes each "RUN …" explicitly, often with DO-NOT lists)
- Concept lock / finalist selection
- Economic premise (amounts, discount size, FICTIONAL/STAGED framing)
- STORY_LOCK (story-development output) before production

- Any skill or architecture edit (frozen gates require explicit authorization)

- Any outbound message, order or checkout (never done autonomously)
- ChatGPT policy refusal (stop and show Tyrel)

- Production route per slide
- Micro-detail choices and the comment-door map
- Small deterministic touch-ups (disclosed)
